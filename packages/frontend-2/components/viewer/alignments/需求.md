# 双屏联动对比查看功能 · 需求文档

**版本**: v2.0\
**状态**: 需求变更中\
**最后更新**: 2026-05-17\
**所属模块**: Viewer / 联动配置（Alignments）

***

## 一、变更背景

在 BIM 施工管理场景中，工程师需要同时对照 **CAD 图纸** 与 **Speckle 三维模型** 做位置校验与问题定位。

当前 `alignments` 模块已经完成了第一版分屏能力，但核心交互仍偏“临时对比”模式：

- 左屏文件仅做本地上传，不可复用。
- 校准仅支持单点平移 + scale 估算，无法处理图纸与模型存在平面旋转的情况。
- 双屏联动依赖相机同步，实际使用中对 CAD 图纸帮助有限。

本轮需求变更后，模块目标从“临时分屏 + 相机联动”升级为“**可保存的双屏联动方案 + 基于校准的点位联动**”。

***

## 二、本轮变更摘要

### 2.1 与旧版相比的核心变化

1. 后端新增 **图纸列表**，用于保存左屏上传的 CAD 文件。
2. 后端新增 **联动配置列表**，用于保存已完成的双屏联动方案。
3. 面板打开时不再只是配置开关，而是先展示“已保存联动列表”，用户点击后可直接加载。
4. 新增“新增联动”入口，弹窗内完成“选择左屏图纸 / 上传新图纸 / 填写联动信息”。
5. **取消相机联动**，改为“校准后点位联动”：
   - 左屏双击某点，右屏自动聚焦到对应位置。
   - 右屏双击某点，左屏显示显著 icon 标记对应位置。
6. 校准由单点升级为 **三点校准**，拟合 `平移 + 缩放 + 绕 Z 轴旋转`。
7. 左屏 CAD 以线图为主，需强化拾点容错，不要求精确命中线段本身。

### 2.2 对现有实现的影响

- 现有 `CameraSync.ts` 的“相机双向同步”不再是主功能，后续应改造成“点位换算 / 联动导航”能力。
- 现有 `CadViewer.vue` 的“左屏直接上传”入口不再作为主入口，上传需迁移到“新增联动”弹窗。
- 现有“单点校准”流程需要整体替换为“三点校准向导”。

***

## 三、产品目标

### 3.1 业务目标

- 让用户进入页面后能快速看到“这个项目已有哪几组双屏联动方案”。
- 让用户能复用已上传的左屏图纸，而不是每次重新上传。
- 让双屏联动更贴近业务任务: “查某个点在另一侧对应哪里”，而不是强求两个相机视角一致。

### 3.2 使用目标

- 用户打开面板后，优先做“选已有方案并加载”。
- 若没有现成方案，用户点击“新增联动”，在一个弹窗里完成文件选择、上传、校准、保存。
- 校准完成后，双屏进入“点位联动模式”，支持双击查找对应位置。

## 五、功能需求

### 5.1 数据实体

本轮前后端至少涉及两类持久化数据。

#### A. 图纸列表

用于保存当前项目下可供左屏使用的 CAD 图纸文件。

建议字段：

```ts
interface AlignmentDrawingFile {
  id: string
  projectId: string
  fileName: string
  fileType: 'dxf'
  fileSize: number
  fileUrl: string
  createdAt: string
  createdBy?: {
    id: string
    name: string
  }
}
```

#### B. 联动配置列表

用于保存一组已完成的双屏联动方案。

建议字段：

```ts
interface AlignmentConfig {
  id: string
  projectId: string
  name: string
  description?: string
  drawingFileId: string
  splitRatio: number
  calibration: {
    points: Array<{
      index: 1 | 2 | 3
      cad: { x: number; y: number; z: number }
      speckle: { x: number; y: number; z: number }
    }>
    transform: {
      dx: number
      dy: number
      dz: number
      scale: number
      rotationZ: number
    }
  }
  createdAt: string
  updatedAt: string
}
```

### 5.2 页面初始化与默认行为

- 用户打开 `Alignments` 面板时，前端立即读取：
  - 图纸列表
  - 联动配置列表
- 若当前项目存在已保存联动配置：
  - 面板主视图默认展示配置列表
  - 用户点击任一配置项后，加载对应左屏图纸和校准结果，并进入分屏模式
- 若当前项目暂无联动配置：
  - 面板展示空状态说明
  - 重点引导用户点击“新增联动”

***

### 5.3 左侧面板交互设计

> 本轮重点不是简单“把控件堆上去”，而是让用户明确知道下一步做什么。

#### 面板信息架构

面板建议分为 3 个层级：

1. **联动列表区**
   - 默认主视图
   - 展示当前项目下所有已保存联动配置
   - 每项显示：名称、关联图纸名、更新时间、是否已校准
   - 点击某项后直接加载
2. **主操作区**
   - `新增联动`
   - `编辑当前联动`
   - `删除当前联动`
   - `另存为`
3. **当前联动详情区**
   - 当前图纸
   - 分屏比例
   - 校准状态
   - 三点校准结果摘要
   - “重新校准”入口

#### 推荐交互流程

##### 场景 A：用户只想查看已有联动

1. 打开面板
2. 看到已保存联动列表
3. 点击某个联动项
4. 系统进入分屏并加载图纸
5. 用户直接开始左右双击联动查看

##### 场景 B：用户想新建联动

1. 点击“新增联动”
2. 打开弹窗
3. 在弹窗中先选择已有图纸；若没有合适图纸，则上传新图纸
4. 填写联动名称
5. 完成三点校准
6. 点击保存
7. 保存成功后自动关闭弹窗并加载新联动

##### 场景 C：用户想修正已有联动

1. 从列表中加载某个联动
2. 点击“编辑当前联动”
3. 打开弹窗并带出当前配置
4. 用户重新校准或更换图纸
5. 保存后覆盖当前联动

#### 不推荐的交互

- 不建议让用户在左屏空白画布上直接上传文件作为主入口。
- 不建议面板打开后先看到大量参数输入框，应该先看到“可直接使用的联动方案”。
- 不建议把“三点校准”的 6 次点击隐藏成黑盒，应持续提示当前第几步、正在采集哪一侧。

***

### 5.4 新增联动弹窗

#### 弹窗目标

让用户在一个聚焦流程中完成：

- 选择或上传左屏图纸
- 填写联动名称
- 执行三点校准
- 保存联动配置

#### 弹窗建议结构

1. 基本信息
   - 联动名称
   - 备注说明（可选）
2. 左屏图纸
   - 图纸下拉选择
   - 上传新图纸按钮
   - 上传进度 / 失败提示
3. 分屏与预览
   - 左侧 CAD 预览
   - 右侧 Speckle Viewer
   - 分屏比例调整
4. 三点校准
   - 显示当前步骤
   - 展示已完成点位数量 `1/3`、`2/3`、`3/3`
   - 支持“上一步重选”与“重置校准”
5. 保存区
   - 保存联动
   - 取消

#### 校准步骤文案

建议采用显式向导提示：

1. 请选择 **第 1 个基准点**：先点左屏 CAD，再点右屏 BIM
2. 请选择 **第 2 个基准点**：先点左屏 CAD，再点右屏 BIM
3. 请选择 **第 3 个基准点**：先点左屏 CAD，再点右屏 BIM
4. 系统计算校准结果并预览

***

### 5.5 双屏联动方式

> 本轮取消相机联动，改为“点位联动”。

#### 左屏 → 右屏

- 用户在左屏 CAD 中 **双击** 某个位置。
- 系统将该点从 CAD 坐标系转换到 Speckle 坐标系。
- 右屏执行“聚焦到对应点”的动作：
  - 相机以当前视角为基础飞行到对应点附近
  - target 对准该点
  - 可附带短暂 pulse / marker 提示

#### 右屏 → 左屏

- 用户在右屏 Speckle Viewer 中 **双击** 某个位置。
- 系统将该点从 Speckle 坐标系转换到 CAD 坐标系。
- 左屏不强制移动相机，可先提供更稳定的轻量反馈：
  - 在 CAD 对应位置显示高亮 icon / marker
  - marker 具备显著颜色、呼吸或闪烁效果
  - 若点位不在当前可见区域，可选择顺带平移视图让该 marker 进入画面中央附近

#### 联动前提

- 仅当当前联动配置完成三点校准后，才允许点位联动。
- 未完成校准时，双击操作应显示明确提示，而不是静默失败。

***

### 5.6 CAD 拾点优化

CAD 图纸以线、折线、细小几何为主，传统射线命中常常难用，因此左屏拾点需做容错优化。

#### 优化目标

- 用户点击接近线段即可拾到合理点位。
- 不要求完全命中几何表面。
- 在大比例缩放或密集线段区域仍能基本可用。

#### 建议策略

1. **屏幕空间容差拾取**
   - 不只看 3D 射线首个命中
   - 以鼠标点为中心，在一定像素半径内查找最近线段/顶点
2. **优先吸附到可解释点**
   - 端点
   - 折点
   - 最近线段投影点
3. **提供视觉反馈**
   - hover 或校准时显示候选点小圆点
   - 点击后显示确认 marker
4. **校准模式容差大于普通模式**
   - 校准时可适当放宽容差半径
   - 普通双击联动时保持适中，避免误吸附

***

### 5.7 三点校准

#### 目标

用 3 组对应点拟合下列变换：

- 平移 `dx / dy / dz`
- 缩放 `scale`
- 绕 Z 轴旋转 `rotationZ`

#### 适用前提

- CAD 与 BIM 的主要姿态差异来自平面旋转，而不是任意 3D 姿态扭转。
- 场景以建筑平面或近似水平对齐模型为主。

#### 校准流程

每个校准点都分两步：

1. 点击左屏 CAD 点
2. 点击右屏 Speckle 对应点

完整流程共 3 轮，共 6 次点击。

#### 结果产出

校准成功后得到：

```ts
interface AlignmentTransform {
  dx: number
  dy: number
  dz: number
  scale: number
  rotationZ: number
}
```

#### 校准约束

- 三个点不允许完全重合。
- 三个点不应近乎共线，否则提示“请重新选择更分散的特征点”。
- 若拟合残差过大，应提示校准质量较差，建议重新选点。

***

### 5.8 配置保存与恢复

- 点击保存后，将当前联动配置写入“联动配置列表”。
- 再次进入页面或重新打开面板时，可从列表直接恢复：
  - 左屏图纸
  - 分屏比例
  - 三点校准点位
  - 变换参数 `dx / dy / dz / scale / rotationZ`

#### 本轮不要求保存的内容

- 左右相机的实时姿态
- 相机联动开关
- 临时 marker 状态

***

### 5.9 删除与覆盖策略

- 用户编辑已有联动并点击保存时，默认覆盖原配置。
- 用户希望保留原配置时，可使用“另存为”创建新配置。
- 删除联动配置时需二次确认。
- 删除图纸文件时，若仍被某些联动配置引用，应禁止删除或给出依赖提示。

## 六、接口要求

> 用户已确认本轮前端采用 **直连后端接口** 的方式。

### 6.1 图纸列表接口

- `GET /alignment/drawings`
  - 读取当前项目图纸列表
- `POST /alignment/drawings`
  - 上传新图纸
- `DELETE /alignment/drawings/:id`
  - 删除图纸

请求建议包含 `projectId` 或放入路径中，由后端统一确定项目上下文。

### 6.2 联动配置接口

- `GET /alignment/configs`
  - 读取当前项目联动配置列表
- `GET /alignment/configs/:id`
  - 读取联动配置详情
- `POST /alignment/configs`
  - 新建联动配置
- `PUT /alignment/configs/:id`
  - 更新联动配置
- `DELETE /alignment/configs/:id`
  - 删除联动配置

### 6.3 前端接入要求

- 前端直接调用后端服务，不再假设本轮由 Nuxt server API 中转。
- 所有列表接口都应带加载态、空态、失败重试态。
- 上传接口应支持进度反馈。

***

## 七、UI / UX 要求

### 7.1 分屏布局

- 默认分屏比例：左 50% / 右 50%
- 允许拖拽分割线调整比例，范围 `20% ~ 80%`
- 分屏模式由加载联动配置或新建联动成功后进入

### 7.2 面板默认视图

- 打开面板后，优先展示“已保存联动列表”
- 当前无数据时，显示空状态插画 / 文案 + “新增联动”主按钮

### 7.3 校准提示

- 校准时左右视图均要有显著提示条
- 当前第几个点、当前应点击哪一侧，必须持续可见
- 已选中的点应显示 marker，并支持撤销最近一步

### 7.4 联动反馈

- 左击 / 双击成功后，目标侧必须出现显著反馈
- 右屏聚焦时建议带平滑飞行动画
- 左屏 marker 建议使用高亮色、带描边或脉冲动画，避免被 CAD 线稿淹没

## 八、非功能需求

| 类别       | 要求                                           |
| -------- | -------------------------------------------- |
| **性能**   | 图纸列表与联动列表首屏加载可感知时间 < 1s；50MB 内 DXF 加载首帧 < 3s |
| **可用性**  | 单侧渲染异常不应拖垮另一侧；校准失败时要能重试                      |
| **兼容性**  | 支持 Chrome / Edge 最新稳定版；暂不考虑移动端               |
| **安全**   | 图纸列表只返回当前项目有权限的文件；配置列表只返回当前项目数据              |
| **可维护性** | 校准变换、点位换算、UI 状态机建议拆分，避免继续把逻辑堆在单组件内           |

## 九、前端实现建议

### 9.1 建议保留并扩展的模块

- `Panel.vue`
  - 从“参数面板”改造成“联动列表 + 当前联动操作面板”

  - 保留分屏与拖拽逻辑

  - 保留 CAD 渲染

  - 图纸列表 / 联动配置列表的接口封装

- `CameraSync.ts`
