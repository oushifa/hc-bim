# 双屏联动对比查看功能 · 需求文档

**版本**: v1.0  
**状态**: 草稿  
**最后更新**: 2026-05-13  
**所属模块**: Viewer / 联动配置（Alignments）

---

## 一、背景与目标

在 BIM 施工管理场景中，工程师需要同时对照 **CAD 设计图纸**（DXF / OBJ 等轻量化格式）与 **Speckle 三维模型** 进行空间位置校验、质量验收比对。  
当前系统的 Viewer 只能单屏显示 Speckle 模型，无法与 CAD 设计文件并排比对，导致工程师需要在两个窗口之间来回切换，效率低下。

**目标**：在同一页面内提供 **左右分屏视图**，左屏渲染 CAD 轻量化模型，右屏渲染 Speckle Viewer 模型，并支持 **相机联动同步**，使两个视角实时跟随，实现精准的设计–实体比对。

## 三、功能需求

### 3.1 分屏布局

- **默认分屏比例**：左屏 50% / 右屏 50%，支持拖拽中间分割线自由调整比例（最小宽度各 20%）。
- **左屏**：CAD 轻量化模型查看器（基于 Three.js 渲染 DXF / OBJ / glTF）。
- **右屏**：现有 Speckle Viewer（`@speckle/viewer`）。
- 分屏模式由 **联动配置（Alignments）侧边面板** 触发，点击面板内「开启分屏」后页面进入分屏模式；关闭面板或点击「退出分屏」后恢复单屏。

### 3.2 CAD 模型上传（v1）

> **v1 范围说明**：本版本不涉及服务端文件存储。CAD 文件由用户在当前会话中本地上传，仅在浏览器内存中保留，页面刷新后需重新上传。

- 左屏顶部提供 **「上传 CAD 文件」按钮**，点击后弹出系统文件选择框，支持格式：`.dxf`。
- 文件选取后在**浏览器端直接读取**（`FileReader` / `URL.createObjectURL`），通过 Three.js Loader 解析并渲染到左屏；**不向服务器上传，不做持久化存储**。
- 渲染期间左屏显示加载进度条（基于文件解析进度回调），加载完成后自动适应视图（`fitToBox`）。
- 支持**拖拽文件**到左屏区域触发加载，等价于点击上传按钮选择文件。
- 若用户希望更换文件，再次点击上传按钮或拖拽新文件，旧模型自动销毁并释放内存（`geometry.dispose()` / `texture.dispose()`）。

### 3.3 相机模型

| 属性       | 说明                                                        |
| ---------- | ----------------------------------------------------------- |
| `position` | 相机世界坐标 `{x, y, z}`                                    |
| `target`   | 相机观察目标点（lookAt）`{x, y, z}`                         |
| `zoom`     | 正交相机缩放倍率（Orthographic）或视野角（Perspective FOV） |
| `type`     | `perspective` \| `orthographic`                             |

- 两个视图共享同一套相机状态模型，联动时以**触发方视图的相机状态**覆盖另一方。
- 考虑到 CAD 与 BIM 坐标系可能存在偏移，联动配置面板提供 **坐标偏移（Offset）** 设置：`dx / dy / dz / scale`，在同步时自动换算。

### 3.4 相机同步（核心功能）

#### 触发方式

- 联动配置侧边面板内设置「同步相机」**Toggle 开关**。
- 开关开启时，按钮高亮（主题色 + 图标动效），并在分屏顶部显示「相机已联动」状态提示条。

#### 同步机制

```
用户操作左屏相机
  → 左屏 Three.js OrbitControls 触发 change 事件
  → 提取当前 position / target / zoom
  → 应用坐标偏移换算
  → 调用 Speckle CameraController.setView({ position, target })
  → 右屏视图更新

用户操作右屏相机（对称逻辑）
  → Speckle Viewer cameraUpdate 事件
  → 逆换算坐标偏移
  → 调用 Three.js camera.position.set(...) + controls.target.set(...)
  → 左屏视图更新
```

- 同步更新使用 **requestAnimationFrame** 节流，避免循环触发（添加 `isSyncing` flag 防循环）。
- 相机同步精度：position 误差 ≤ 0.001 单位，zoom 误差 ≤ 0.01%。

#### 解除联动

- 关闭 Toggle 后恢复独立操作，两个视图相机保持各自最后状态。

### 3.5 坐标对齐辅助

- 联动配置面板提供「一键校准」功能：用户分别在左屏和右屏点击同一特征点（如柱角），系统自动计算两坐标系之间的偏移量并填入 Offset 字段。
- 校准点选取使用射线投射（Raycaster），在三维空间中拾取点击位置。

### 3.6 配置持久化

- 点击面板顶部的「保存」按钮（`Save` 图标），将以下配置通过 REST API 持久化：

```typescript
interface AlignmentConfig {
  lightModelId: string // 所选 CAD 文件 ID
  splitRatio: number // 分屏比例（0.2 ~ 0.8）
  cameraSync: boolean // 是否开启同步
  offset: {
    dx: number
    dy: number
    dz: number
    scale: number
  }
  savedCameraState?: {
    cad: CameraState
    speckle: CameraState
  }
}
```

- 接口：`PUT /api/viewer/alignment-config/:projectId`
- 进入 Viewer 时自动读取并还原配置（`GET /api/viewer/alignment-config/:projectId`）。

## 四、非功能需求

| 类别       | 要求                                                        |
| ---------- | ----------------------------------------------------------- |
| **性能**   | 相机同步延迟 < 50ms；CAD 模型首帧渲染 < 3s（50MB 以内文件） |
| **兼容性** | 支持 Chrome 100+、Edge 100+、Firefox 110+；不支持移动端     |
| **可用性** | 分屏模式下，单个视图渲染异常不影响另一视图正常使用          |
| **无障碍** | 同步开关提供 `aria-label`，键盘可操作（Space/Enter 切换）   |
| **安全**   | CAD 文件列表仅展示当前项目内用户有权限访问的文件            |
