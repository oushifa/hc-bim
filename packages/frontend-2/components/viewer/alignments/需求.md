### 视图联动

1. 需求
   - 联动 Civil3D 中的视图（View）
   - 联动 Civil3D 中的剖面图（Profile View）
   - 联动 Civil3D 中的纵断面图（Profile）
   - 联动 Civil3D 中的其他模型视图
2. 难点
   - Civil3D 中的视图是静态的，而模型是动态的
   - 如何在模型上画出剖面图？
   - 如何在 Civil3D 中画出剖面图？
   - Civil3D 模型比较大，加载需要时间
3. 实现方案
   - 使用 @speckle/extractors-civil-3d 提取 Civil3D 数据
   - 使用 @speckle/viewer 渲染 Civil3D 数据
   - 使用 @speckle/viewer-controls 渲染 Civil3D 数据
